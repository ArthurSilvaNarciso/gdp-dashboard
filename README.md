# Memory · protótipo funcional

App de estudo ativo em ciclos curtos (Desafio → Esforço → Recompensa → Consolidação), com revisão espaçada inspirada no FSRS, simulado cronometrado, caderno de erros e trilhas com casos reais.

Arquivos estáticos: `index.html` + `img/`. Publicado na Vercel como projeto `memory-app`.
